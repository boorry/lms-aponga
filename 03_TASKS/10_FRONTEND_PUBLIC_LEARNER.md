# Frontend — Public & Learner

Références : `02_PROJECT/SCREEN_CATALOGUE.md` (écrans Public/Learner), `02_PROJECT/PRD_UI.md` (principes UI), `02_PROJECT/SCREEN_CONTRACT.md` (format à renseigner pour chaque écran livré).

Implémenter les écrans Public et Learner du catalogue (consommant T-201, T-202, T-203 côté API). Utiliser le template uniquement comme source visuelle (`05_FRONTEND/template-source/`) ; le code réel vit dans `05_FRONTEND/production-ui/`.

Chaque écran livré doit avoir sa fiche renseignée dans `02_PROJECT/SCREEN_CONTRACT.md` (route, rôle(s) autorisé(s), endpoint(s) consommés, états loading/empty/error/success). Aucun écran ne doit consommer un endpoint absent de `00_REFERENCE/08_CONTRAT_API.md`.

## Acceptance
Parcours découverte → inscription → apprentissage → soumission → feedback via API réelle. Fiches `SCREEN_CONTRACT.md` à jour pour chaque écran livré.
