# Definition of Done

Une tâche est DONE seulement si :

- code compilable ;
- tests adaptés présents et verts ;
- critères d'acceptation démontrés ;
- invariants non régressés ;
- permissions testées ;
- migration revue si DB ;
- API documentée si endpoint ;
- logs/erreurs cohérents si opération sensible ;
- documentation mise à jour si comportement public ;
- `DONE.md` mis à jour ;
- aucun blocker connu masqué.
