# Blockers

Aucun blocker d'architecture connu après la revue de verrouillage du 21/09/2026.

Un nouveau blocker doit contenir :

- ID ;
- date ;
- mission ;
- fichier/règle concerné ;
- problème ;
- impact ;
- décision attendue ;
- statut.

Ne jamais masquer un blocker pour faire passer une Quality Gate.
