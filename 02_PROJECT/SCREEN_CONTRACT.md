# Contrat écran/API

Chaque écran doit documenter :
- route frontend ;
- rôle(s) autorisé(s) ;
- endpoint(s) consommés ;
- états loading/empty/error/success ;
- permissions ;
- pagination/filtres ;
- comportement offline si applicable ;
- événements analytics si retenus.

Aucun écran ne doit inventer un endpoint absent de `00_REFERENCE/08_CONTRAT_API.md`.
