# 16 — Stack technique

**La source normative unique est `09_ENVIRONMENT/STACK_TECHNIQUE.md`.**

Ce fichier existait auparavant comme une copie complète de ce tableau. Il a été réduit à ce pointeur lors de l'audit final (voir `FINAL_AUDIT.md`) : deux tableaux de versions maintenus séparément finissent toujours par diverger silencieusement, ce qui est précisément le risque qu'une conception « fermée » doit éliminer.

`02_ARCHITECTURE_CONCEPTION.md` §7.1 décrit les composants de la stack au niveau architecture (sans version). `09_ENVIRONMENT/STACK_TECHNIQUE.md` porte les versions exactes et les règles de verrouillage. `CLAUDE.md` §3 reprend ce même tableau pour un accès immédiat par l'agent de développement — en cas de divergence entre `CLAUDE.md` et `09_ENVIRONMENT/STACK_TECHNIQUE.md`, ce dernier fait foi.
